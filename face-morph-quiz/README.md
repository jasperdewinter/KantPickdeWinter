# Face Morph Quiz

An interactive browser-based quiz that blends two illustrated faces and asks players to guess who is hidden in the morph.

## Getting started

1. Open `face-morph-quiz/index.html` directly in your browser, or start a quick local server (e.g., `python -m http.server`) from the repository root.
2. Use the morph slider to reveal each portrait blend, then choose the name you think is hidden.
3. Click **Next round** to cycle through all available morphs.

Everything is self-contained: the illustrated faces are embedded as inline SVG data URIs and no network requests are required.
